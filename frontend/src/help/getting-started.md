# Getting Started with Aurora

Aurora is a QA management platform that helps you track test results, generate AI-powered Playwright tests, and monitor your applications around the clock — all from a single desktop app.

---

## Key Concepts

### Features & Products
A **Feature** (or Product) is the thing you're testing — "Mobile App", "Checkout Flow", "API Gateway". Features are the top-level unit that groups your tests and initiatives together.

### Test Packs
A **Test Pack** is a curated collection of individual test scripts, run as a batch with one click. Build packs from the tests generated by the AI Test Generator.

### Synthetic Monitoring
**Synthetic Monitoring** runs your test scripts on a schedule — every hour, every 15 minutes — so you catch failures before your users do.

### Initiatives
An **Initiative** is a strategic goal tied to a feature: "Q2 Automation Coverage", "API Regression Suite". Initiatives track your QA progress against a target date and measure coverage.

---

## Quick Start

1. **Create a Feature** — Go to **Settings → Features** and create your first feature or product.
2. **Generate a Test** — Go to **Testing → Test Generator**, describe what to test in plain English, and provide a `https://` URL.
3. **Run the Test** — Once generated, run it from **Testing → Test Packs**.
4. **Promote to Synthetic** — When a test is stable, promote it to Synthetic Monitoring for continuous execution.
5. **Create an Initiative** — Link your feature to a strategic goal and track progress over time.

---

## System Requirements

| Component | Requirement |
|-----------|-------------|
| Backend | Aurora backend running on `localhost:3000` |
| Browser Tests | Playwright (bundled — no extra setup) |
| AI Generation | API key from Anthropic, OpenAI, or Azure OpenAI |
| OS | macOS, Windows, or Linux |

Configure your AI provider under **Settings → System** before using the Test Generator.

---

## The Setup Wizard

When you first launch Aurora, the Setup Wizard walks you through:

1. Creating your manager profile
2. Creating your first Feature
3. Creating your first Initiative
4. Understanding the Test Generator and Test Packs
5. Understanding Synthetic Monitoring

You can re-run the wizard at any time from **Settings → Profile → Launch Setup Guide**.
